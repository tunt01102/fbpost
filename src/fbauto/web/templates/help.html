📖 Hướng dẫn cho người không rành IT

A. Google AI Ultra không API key (khuyên dùng)

Google AI Ultra là tên gói thuê bao, không phải tên model. Từ 18/06/2026, tài khoản cá nhân AI Pro/Ultra dùng Antigravity CLI thay cho Gemini CLI.

  1. macOS/Linux, cài bằng curl -fsSL https://antigravity.google/cli/install.sh | bash. Windows PowerShell dùng irm https://antigravity.google/cli/install.ps1 | iex.
  2. Chạy agy và đăng nhập bằng đúng tài khoản có AI Ultra.
  3. Chạy agy models nếu muốn xem model đang được cấp.
  4. Vào Cài đặt, chọn Google AI Ultra — Antigravity CLI. Nên để model trống để dùng Auto.
  5. Bấm Kiểm tra kết nối AI, rồi tạo một bài thử.

App chạy chế độ chính thức agy -p và dùng phiên Google lưu trong keyring của máy. App không nhận mật khẩu, cookie hay API key. Hạn mức/model phụ thuộc gói Google.

A2. Các AI khác

ChatGPT (gói Plus/Pro): cài Codex CLI của OpenAI, mở terminal gõ codex và đăng nhập bằng "Sign in with ChatGPT". Sau đó vào Cài đặt chọn provider codex_cli → bấm "Kiểm tra kết nối AI".

Gemini CLI cũ: chỉ giữ cho tài khoản Enterprise hoặc cách xác thực API được Google tiếp tục hỗ trợ; tài khoản Ultra cá nhân không chọn mục này.

Claude (gói Pro/Max): cài Claude CLI, gõ claude để đăng nhập. Chọn provider claude_cli.

Với các provider CLI, bạn không nhập API key vào app.

B. Lấy Chìa khoá kết nối Facebook (Fanpage) — khuyến nghị

  1. Bạn phải là Quản trị viên của Fanpage.
  2. Vào developers.facebook.com/apps → Create App → chọn Business.
  3. Mở Graph API Explorer → chọn app → Generate Access Token → tick các quyền: pages_show_list, pages_read_engagement, pages_manage_posts.
  4. Đổi sang token dài hạn, lấy Page ID + Page Token.
  5. Dán vào Cài đặt → Kết nối Facebook → bấm "Kiểm tra".

Token là bí mật — app lưu an toàn trong máy bạn, không gửi đi đâu, không hiển thị lại đầy đủ. Token Page thường hết hạn ~60 ngày, cần gia hạn lại.

C. Đăng bằng trình duyệt (tùy chọn, rủi ro hơn)

Chỉ dùng khi hiểu rõ rủi ro ToS. Cần cài thêm: pip install "fbauto[browser]" rồi playwright install chromium, và đăng nhập một lần để lưu phiên.
