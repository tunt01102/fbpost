Cấu hình Google AI Ultra

“Google AI Ultra” là gói thuê bao. Tên model thay đổi theo đợt phát hành; chạy agy models để xem model tài khoản đang được dùng.

Nút đăng nhập có thể mở trình duyệt và mất vài phút. App chỉ nhận kết quả thành công/thất bại; credential do Antigravity lưu trong keyring.

📖 Cài Google AI Ultra không API key — từng bước
Lưu ý từ 18/06/2026: Google đã chuyển tài khoản cá nhân Free/AI Pro/AI Ultra từ Gemini CLI sang Antigravity CLI. Không chọn gemini_cli cho tài khoản Ultra cá nhân.
  1. Kiểm tra gói: đăng nhập đúng tài khoản Google đang có gói Google AI Ultra. Gói Ultra là quyền truy cập, không phải tên model gemini-ultra.
  2. Cài Antigravity CLI.
    macOS/Linux: curl -fsSL https://antigravity.google/cli/install.sh | bash Windows PowerShell: irm https://antigravity.google/cli/install.ps1 | iex Chỉ chạy lệnh sau khi bạn đã kiểm tra tên miền là antigravity.google.
  3. Đăng nhập một lần: mở Terminal/PowerShell, chạy agy Trình duyệt sẽ mở. Chọn đúng tài khoản Google AI Ultra và hoàn tất đăng nhập. Phiên đăng nhập được CLI lưu trong keyring của hệ điều hành; app không đọc mật khẩu.
  4. Xem model được cấp: thoát màn hình tương tác rồi chạy agy models Khuyên dùng để trống ô “Model viết bài” (Auto). Nếu muốn ghim model, sao chép đúng model slug/tên mà lệnh trên hiển thị; đừng tự nhập gemini-ultra.
  5. Cấu hình app: chọn “Google AI Ultra — Antigravity CLI”, để model trống, bấm Lưu cấu hình AI, rồi bấm Kiểm tra kết nối AI.
  6. Tạo bài thử: vào Tạo bài, nhập một chủ đề ngắn. App gọi agy -p ... ở chế độ không tương tác và dùng phiên Google đã lưu, hoàn toàn không cần biến GEMINI_API_KEY.
Nếu lỗi: chạy lại agy để đăng nhập; kiểm tra agy models; nếu Terminal báo không tìm thấy lệnh, đóng/mở lại Terminal sau khi cài. Hạn mức và model phụ thuộc gói/tài khoản Google.

Tài liệu chính thức: Antigravity CLI · thông báo chuyển đổi ngày 18/06/2026.

2. Kết nối Facebook (Fanpage)

Khuyến nghị dùng Fanpage + Chìa khoá kết nối (Page token) — an toàn, đúng luật. Token được lưu cục bộ (Keychain/.env), không gửi đi đâu, không hiển thị lại.

📖 Hướng dẫn tạo app & lấy token — từng bước (cho người mới)

Chỉ đăng được lên Facebook Page (trang) do bạn quản trị — không phải profile cá nhân. Cần: một Page + một Meta App.

  1. Tạo Meta App: vào developers.facebook.com/apps → Create App → chọn loại Business.
  2. Lấy App ID / App Secret (dùng để gia hạn token): trong app → Settings → Basic.
  3. Lấy token thử nghiệm: mở Graph API Explorer → chọn app của bạn → Generate Access Token → cấp các quyền:
    pages_show_list pages_read_engagement pages_manage_posts pages_manage_engagement read_insights
  4. Đổi sang token dài hạn (60 ngày) — mở URL sau trên trình duyệt (thay 3 giá trị APP_ID, APP_SECRET, TOKEN_BƯỚC_3): https://graph.facebook.com/v20.0/oauth/access_token?grant_type=fb_exchange_token&client_id=APP_ID&client_secret=APP_SECRET&fb_exchange_token=TOKEN_BƯỚC_3
  5. Lấy Page ID + Page Token: mở https://graph.facebook.com/v20.0/me/accounts?access_token=TOKEN_DÀI_HẠN Trong kết quả JSON: data[].id = Facebook Page ID · data[].access_token = Page Access Token (loại này thường không hết hạn).
  6. Dán 2 giá trị đó vào ô Page ID và Page Access Token bên trên → Lưu. Kiểm tra nhanh: mở https://graph.facebook.com/v20.0/me?access_token=PAGE_TOKEN phải trả về tên Page (hoặc bấm nút “🔎 Kiểm tra kết nối Facebook”).
⚠ Muốn app đăng cho Page ngoài tài khoản dev/test → cần qua App Review của Meta cho các quyền trên.

🔒 Bảo mật: token là bí mật cá nhân, chỉ lưu trên máy này. Đừng dán token vào chat, email hay tài liệu chia sẻ.
