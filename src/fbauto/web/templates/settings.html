2. Kết nối Facebook (Fanpage)

Khuyến nghị dùng Fanpage + Chìa khoá kết nối (Page token) — an toàn, đúng luật. Token được lưu cục bộ (Keychain/.env), không gửi đi đâu, không hiển thị lại.

📖 Hướng dẫn tạo app & lấy token — từng bước (cho người mới)

Chỉ đăng được lên Facebook Page (trang) do bạn quản trị — không phải profile cá nhân. Cần: một Page + một Meta App.

  1. Tạo Meta App: vào developers.facebook.com/apps → Create App → chọn loại Business.
  2. Lấy App ID / App Secret (dùng để gia hạn token): trong app → Settings → Basic.
  3. Lấy token thử nghiệm: mở Graph API Explorer → chọn app của bạn → Generate Access Token → cấp các quyền:
    pages_show_list pages_read_engagement pages_manage_posts pages_manage_engagement read_insights
  4. Đổi sang token dài hạn (60 ngày) — mở URL sau trên trình duyệt (thay 3 giá trị APP_ID, APP_SECRET, TOKEN_BƯỚC_3): https://graph.facebook.com/v20.0/oauth/access_token?grant_type=fb_exchange_token&client_id=APP_ID&client_secret=APP_SECRET&fb_exchange_token=TOKEN_BƯỚC_3
  5. Lấy Page ID + Page Token: mở https://graph.facebook.com/v20.0/me/accounts?access_token=TOKEN_DÀI_HẠN Trong kết quả JSON: data[].id = Facebook Page ID · data[].access_token = Page Access Token (loại này thường không hết hạn).
  6. Dán 2 giá trị đó vào ô Page ID và Page Access Token bên trên → Lưu. Kiểm tra nhanh: mở https://graph.facebook.com/v20.0/me?access_token=PAGE_TOKEN phải trả về tên Page (hoặc bấm nút “🔎 Kiểm tra kết nối Facebook”).
⚠ Muốn app đăng cho Page ngoài tài khoản dev/test → cần qua App Review của Meta cho các quyền trên.

🔒 Bảo mật: token là bí mật cá nhân, chỉ lưu trên máy này. Đừng dán token vào chat, email hay tài liệu chia sẻ.
